# Directorio de APIs — BNH Medical

Proyecto listo para subir a **GitHub** y desplegar en **Vercel**.

## Cambios aplicados
- **Logotipo corregido:** funciona tanto si `bnh-medical-logo.png` está en la raíz del repositorio como dentro de `assets/bnh-medical-logo.png`.
- **Datos actualizados (`app.js`):** incluye tu clave `CLAVE_GERENCIAL`, las 7 herramientas de `APIS_USUARIOS` y los 5 paneles de `APIS_GERENCIALES`.
- **Interfaz minimalista y moderna:** buscador en tiempo real, contador de APIs visibles, selector de paletas con guardado en `localStorage`, enlaces largos abreviados visualmente y botones **Abrir** y **Copiar enlace**.
